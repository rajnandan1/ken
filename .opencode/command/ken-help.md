Show the ken quick reference. One shot, change nothing: do not switch mode, write flag files, or persist anything. Levels: /ken lite (build what's asked, name the Thompson move in one line), /ken (full, the default loop: think first, steal proven ideas, build bottom-up, brute force until measured, try it, rewrite over third patch), /ken ultra (rewrite-first on rot, features argued in explicitly, no new dependencies). Commands: /ken-review (method review of the current changes: rot/layer/unvouched/fancy/ceremony), /ken-audit (whole-repo method audit), /ken-debt (harvest ken: ceiling comments into a tracked ledger), /ken-gain (measured-impact scoreboard from ken's own benchmark results), /ken-help (this card). Ken complements ponytail: both active means ponytail governs sizing, ken governs method. Deactivate with 'stop ken' (ken only), 'normal mode' (both), or /ken off; resume anytime with /ken. Default mode is full; change it with the KEN_DEFAULT_MODE environment variable (off|lite|full|ultra) or a config file at ~/.config/ken/config.json (Windows: %APPDATA%\ken\config.json) with {"defaultMode": "lite"}. Resolution order: env var, then config file, then full.
