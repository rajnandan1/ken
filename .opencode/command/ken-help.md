Show the ken quick reference without changing mode or writing files. Levels: /ken lite (build what's asked, name the Thompson move in one line), /ken (full, the default loop: think first, steal proven ideas, build bottom-up, brute force until measured, try it, rewrite over third patch), /ken ultra (rewrite-first on rot, require an argument for each feature, add no dependencies). Commands: /ken-review (method review of the current changes: rot/layer/unvouched/fancy/ceremony), /ken-audit (whole-repo method audit), /ken-debt (harvest ken: ceiling comments into a tracked ledger), /ken-gain (measured-impact scoreboard from ken's benchmark results), /ken-help (this card). Deactivate with 'stop ken', 'normal mode', or /ken off; resume with /ken. Default mode is full. Change it with the KEN_DEFAULT_MODE environment variable (off|lite|full|ultra) or a config file at ~/.config/ken/config.json (Windows: %APPDATA%\ken\config.json) containing {"defaultMode": "lite"}. Resolution order: env var, config file, full.
